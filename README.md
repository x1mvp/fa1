# 🤖 Open Agent Factory

A modular, open-source multi-agent orchestration framework that operates entirely on free, self-hosted infrastructure.

## 🚀 Quick Start (Windows)

### Prerequisites
- Windows 10/11 with PowerShell
- Docker Desktop for Windows
- Python 3.10+ installed
- GitHub account

### Step 1: Clone and Bootstrap
```powershell
# Clone the repository
git clone https://github.com/x1mvp/fa1
cd fa1

# Run the bootstrap script
.\bootstrap.ps1
